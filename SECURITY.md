# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The MobileSQL security team takes application and data integrity seriously.

If you discover a security vulnerability in MobileSQL, please report it privately:

1. **Email**: security@mobilesql.dev
2. **Details to include**:
   - Type of vulnerability (e.g., SQL injection, authentication bypass, XSS)
   - Step-by-step reproduction instructions or Proof of Concept (PoC)
   - Affected endpoints or components
   - Impact assessment

We will acknowledge receipt of your vulnerability report within 24 hours and provide regular status updates until a patch is released. Please refrain from publicly disclosing the issue until a fix has been verified and deployed.
