## 🚀 Product Hunt Launch Kit

### Tagline
> **Desktop-grade SQL IDE, visual EXPLAIN cost profiler, and AI Academy in your pocket.**

### Short Description
MobileSQL brings full-featured PostgreSQL 16, SQLite WASM, and MySQL sandbox execution to mobile devices with tactile ergonomics, a visual EXPLAIN plan cost tree, 12 gamified academy modules, and an AI database copilot.

### Maker's Comment
\`\`\`markdown
Hey Product Hunt community! 👋

We built MobileSQL because existing database tools and SQL learning platforms were never designed for mobile ergonomics. Trying to debug a query or review indexing logic on a phone was painful.

MobileSQL solves this with:
1. ⚡ Instant <12ms sandbox execution (SQLite WASM client-side + Postgres 16 backend)
2. 📊 Visual EXPLAIN plan cost analyzer that shows bottlenecks on mobile screens
3. 🎓 12 progressive curriculum modules with live test suites and verifiable certificates
4. 🤖 Gemini AI Copilot that turns plain English into optimized SQL statements
5. 📱 100% open source under the MIT License

Try the live demo without creating an account: https://mobilesql.io

We'd love your feedback!
